#### How to use

When enabled, a button will be added to the right of the top bar. Click to open the search.

In addition, the shortcut key `Ctrl+Shift+Alt+F` has been added, which can be modified in the Keymap settings.

Searches the entire document content, including parts that haven't been loaded yet (for long documents with lazy loading). The search uses SiYuan's API to fetch the complete document content, ensuring all matches are found.
